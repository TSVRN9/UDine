Rule 1 — share needs sync. A SHARE toggle is disabled (greyed) while its SYNC is off. Turning SYNC off turns SHARE off with it and deletes the server copy.
Rule 2 — delete ≠ off. DELETE removes what's there now; the toggle stays where it is. If SYNC is still on, the next sync re-uploads. Copy says so.
Rule 3 — schema consequence. Today a stat's server row IS the shared copy (sync == share). Separating them needs a per-stat visibility flag on shared_stats. Decide before building.
